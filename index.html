adaptive aim

Aim follows proportions: when width, depth or height changes differently, each light keeps pointing at the same relative area of the sectional.

When to use which?

Both modes are identical at the reference size. Proportional is the safe default for an unknown sectional size. Use fixed sources only when the studio fixtures must keep their real dimensions.

Reference rig dimensions (advanced)

The sofa size the rig is tuned for right now. When the input equals the reference, the output matches the source T3D 1:1.

How axes & scaling work

Axes: world X↔width(453), Y↔depth(274), Z↔height(77) — inferred from the fill (SourceWidth 500 ≈ 453). Positions and aim directions scale per axis; AttenuationRadius follows the distance. Uniform scaling keeps rotations unchanged.

Per-light breakdown
LighttypeXYZRot P·Y·RIntensitySizeAttenkp

Every field generateT3D writes. Size: rect = W×H (·b BarnDoorLength), spot = r SourceRadius (·s SoftSourceRadius). Atten = AttenuationRadius. Rot = adaptive Pitch·Yaw plus the original Roll. The grey tag next to Intensity is the source value. p = falloff exponent (mode B); mode A uses k² (p = 2).

Calculation formula
1. Scale factors (reference rig 453 × 274 × 77):
sX = W / 453    sY = D / 274    sZ = H / 77
2. New light position and aim:
X′ = X · sX    Y′ = Y · sY    Z′ = Z · sZ
aim′ = normalize(aimX·sX, aimY·sY, aimZ·sZ)
3. Change in distance to the sofa (per light):
d0 = √(X² + Y² + Z²)    d1 = √(X′² + Y′² + Z′²)    k = d1 / d0
4. Effective source radius:
spot:  R = SourceRadius    rect:  R = √(SourceWidth · SourceHeight / π)
5. Mode A — source sizes scale (× k):
Intensity′ = Intensity · k²    SourceWidth/Height/Radius/BarnDoorLength · k
5. Mode B — source sizes fixed:
Intensity′ = Intensity · (k²·d0² + R²) / (d0² + R²)  ≈  Intensity · kp
p = 2·d0² / (d0² + R²)    sharp key → p ≈ 2,  soft fill → p ≈ 1.7
6. Attenuation & unchanged params:
AttenuationRadius′ = AttenuationRadius · k
roll, color, temperature — unchanged; pitch/yaw follow the scaled aim vector

Why not a "pure" inverse square: for large soft sources (fill, left_rim) R is comparable to the distance — the near field — so illuminance falls off gentler than k². When the input equals the reference, k = 1 → the output matches the source rig 1:1.
